## Finding a test

Every practice library shares search, level, year, topic and difficulty filters. Difficulty is **Easy, Medium or Hard**, estimated from the paper's question content, reasoning, calculations, breadth and workload within its division. It is independent of competition tier. Each ready test has a colored text pill (green, amber or red) and a difficulty explanation. Unconverted listings do not receive a guessed difficulty; choosing a difficulty hides them.

The complete original paper remains scrollable beside the answer sheet. Original question numbers and PDF pages identify each field. Converted prompts and answer choices are displayed where available, and supplementary image sheets are included when supplied. The count-up timer is shared across event pages, survives draft reloads, and stops on submission or when viewing a saved result.

## Grading and persistence

After submitting, students can use **Auto Grade** on the saved result. It rechecks nonblank written responses against the existing rubric, preserves MCQ keys and original student text, and updates that attempt's score and percentage. Successful reviews are saved once; repeated requests reuse the saved result. Failures leave the earlier score intact and allow retry. Instructor reviews take precedence. Auto Grade does not create an attempt or grant more progress, points, or assignment credit.

Converted papers without a published answer key may declare `gradingMode: 'ai-generated'`, `keyUrl: null`, and an empty `keys` object. Every question must include its complete `prompt`, choices, and any necessary diagram/table context in `context`; catalog validation rejects bare question-number placeholders. Auto Grade first asks Gemini for independent reference solutions without student answers, then grades the saved answers against those generated criteria. The server validates question IDs, option IDs, criterion weights, score bounds, and completeness. Generated reference answers and estimated scores are labeled as AI-generated; unresolved source context remains pending for instructor review. This supports converted question content, not source-only archive links whose questions have not yet been extracted.

Authenticated server grading ignores client scores. MCQ keys, numerical tolerances, accepted short-answer variants and rubric criteria stay in the server catalog; initial paper responses omit them. Submitted results include corrections: correct MCQ choices are green, written rubric answers are red, and exact student input remains visible. When `GEMINI_API_KEY` is configured, unresolved written criteria are sent without account identifiers to Gemini 3.5 Flash by default (`GEMINI_MODEL` can override it) with a strict JSON rubric response; the server validates every returned question, criterion, and point bound before applying it. Provider failures keep the answer pending for instructor review rather than assigning a guessed score.

MCQ sets require all correct choices. Numerical answers support decimal/scientific notation, fractions, stated units and published tolerance ranges. Equivalent notation not recognized by the parser goes to review. Recognized short answers grade automatically; unmatched nonempty prose is sent to Gemini when configured, rather than receiving a fabricated semantic grade. Blank fields score zero. Instructors review any response the model marks uncertain against the linked full rubric and enter bounded partial credit. Scores and percentages are provisional until that review is complete.

Submission UUIDs are scoped to the authenticated user and paper, making retries idempotent. Each distinct practice paper contributes once to practice progress; the first attempt can complete one pending Practice assignment in that event, while repeat submissions remain available for feedback without additional assignment credit or ranked points. Exact answers and reviewed scores are persisted in `practice_submissions`; `test_attempts` remains the dashboard record. Drafts are saved only in that student's browser under user/division/test-specific keys. Previous-attempt review preserves an unsubmitted draft.
